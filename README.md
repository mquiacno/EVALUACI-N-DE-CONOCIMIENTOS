# EC_XR_YauyoMiguel

Proyecto de realidad extendida (XR) en Unity 6 (6000.3.24f1) con URP y XR Interaction Toolkit 3.3.2.

## Contenido
- Escena: `EC_XR_YauyoMiguel`
- Escenario con piso, iluminación, límites visuales y 5 objetos 3D
- Objetos manipulables con Rigidbody y XR Grab Interactable
- Interacción a distancia con rayo (cambio de color con ChangeColor)
- Reto libre: lanzamiento de objetos con la tecla N

## Cómo probarlo
1. Abrir el proyecto con Unity 6000.3.24f1.
2. Abrir la escena `EC_XR_YauyoMiguel`.
3. Dar Play. Sin visor, usar el XR Device Simulator (mouse y teclado).
